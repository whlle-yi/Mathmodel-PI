# 用户手册

## 1. 安装

1. 运行 `Mathmodel-PI Setup x.y.z.exe`，按向导完成安装（可自定义安装目录）。
2. 首次启动会进入引导页。

## 2. 首次引导

1. **环境检测**：应用会检测 Python 运行时与 XeLaTeX。
   - Python：安装包已内置便携版，正常显示 ✓ 即可；
   - XeLaTeX：未检测到不影响分析与建模，但**论文编译前必须安装** [MiKTeX](https://miktex.org/download) 或 [TeX Live](https://tug.org/texlive/)，安装后重启本应用即可被识别。
2. **模型接入**：选择服务商并填入 API Key（仅保存在本机）。建议选择支持**图像输入**的服务商（智谱 GLM、Claude、GPT、Gemini 等）——赛题视觉核验需要读取题目中的公式与图表。

   > API Key 可随时在「设置」中增删，支持同时配置多家服务商。

## 3. 开始一次建模

1. 顶栏「选择项目」→ ＋ 新建项目 → 命名并选择保存位置。
2. 点击「一键运行全流程」，在表单中：
   - 选择**题目文件**（PDF / DOCX / 图片，建议 PDF）；
   - 选择**附件目录**（官方数据附件，如有）；
   - 选择**侧重点**（精度优先 / 可解释性优先 / 速度优先 / 均衡）；
   - 填写**子问题数量**（未知则交给赛题分析阶段确定）；
   - 选择**模型**。
3. 点击「开始执行」。智能体将按以下流水线连续工作：

   | 序 | 阶段 | 主要产物 |
   |---|---|---|
   | 1 | 赛题分析 | `docs/01-analysis-report.md`（含题面逐页转录） |
   | 2 | 建模求解 | `docs/02-modeling-report.md` |
   | 3 | 编程实现 | `code/`、`results/`、`docs/03-results-report.md` |
   | 4 | 论文策划 | `paper/structure-plan.md`、`paper/page-budget.json` 等 |
   | 5 | 数据图 / 非数据图 | `figures/` |
   | 6 | 论文终稿（两轮独立成稿与审计） | `paper/论文.tex`、`paper/论文.pdf` |
   | 7 | 验收 | `docs/06-verification-report.md` |

4. 顶栏流水线条实时显示各阶段状态；右侧预览区可随时查看报告、图表与论文 PDF。

## 4. 单步执行

流水线条上把鼠标悬停到某个阶段，点击 ▶ 可**单独执行该阶段**。适用场景：

- 全流程在某一阶段失败后，修复后单独重跑该阶段；
- 已有人工产物（如初稿论文），只跑论文终稿或验收阶段。

单步模式下，智能体的提问会以弹窗形式出现，请直接在弹窗中作答。

## 5. 常见问题

**Q：执行中途点「停止执行」会怎样？**
当前会话中止，已落盘的产物保留。可在对应阶段单步重跑。

**Q：机检脚本 FAIL 了怎么办？**
skills 的纪律是「PASS 以脚本 exit 0 为准」：智能体会自行返回对应阶段修正后再继续；若反复失败，查看执行流中的脚本输出定位原因（常见：缺库、LaTeX 缺宏包）。

**Q：XeLaTeX 编译缺宏包？**
MiKTeX 默认开启「缺包即装」，保持联网即可；TeX Live 建议安装 full 版。

**Q：想换/更新建模工作流？**
两种方式：①「设置 → 建模 Skills → 导入 skills 目录」；②高级方式——把个人 skills 放进全局配置目录 `%USERPROFILE%\.mp\skills\`，同名 skill 会覆盖内置版本。

**Q：如何给智能体固定我的偏好（全局/项目两级配置）？**
类似 Codex 的 `.codex`，Mathmodel-PI 使用 `.mp` 配置目录：

| 层级 | 位置 | 作用 |
|---|---|---|
| 全局 | `%USERPROFILE%\.mp\AGENTS.md` + `.mp\skills\` | 所有会话生效：个人偏好、写作习惯、常用假设 |
| 项目 | 工作目录下 `.mp\AGENTS.md` + `.mp\skills\` | 只对当前会话/项目生效：本题约定、数据位置 |

同名 skill 就近覆盖（项目 > 全局 > 导入 > 内置）；首次使用建议从全局 `AGENTS.md` 里的模板改起。

**Q：执行记录（左侧对话流）消失了？**
执行流仅保存在内存中，重启应用后清空；所有产物都在项目目录里，不受影响。
