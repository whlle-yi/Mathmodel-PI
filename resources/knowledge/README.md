# 内置知识库（源文件目录）

这里是随软件分发的**知识素材**，与 `resources/skills/`（行为指令）分工明确：

- skills 教智能体"怎么干活"——整读执行，不参与检索切块；
- 本目录的内容是智能体回答问题时检索引用的"图书馆"——构建时切块进
  `resources/kb-index/builtin.sqlite3`。

## 目录约定

| 目录 | 内容 |
|---|---|
| `methods/` | 方法论：模型适用性、算法对比、选择决策 |
| `writing/` | 论文写作：摘要、图表、语言、篇幅 |
| `competition/` | 竞赛：规则、评审视角、时间策略 |
| `examples/` | 精选案例片段、典型题解 |

## 如何补充知识

1. 把 markdown 文件放进对应目录（或新建主题目录）；
2. 在 `manifest.json` 的 `include` 里确认模式能匹配到（新增 `**/*.md` 类目录无需改）；
3. 运行 `npm run build-kb` 重新生成索引；
4. 重新打包或开发模式重启即生效。

## 排除规则

`manifest.json` 的 `exclude` 用于排除强结构文件（SKILL.md、调度清单等
规则走整读通道）和大体积结构化数据（模型字典走专用查询脚本）。
