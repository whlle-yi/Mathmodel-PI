# 模型选型决策树

> **知识层文件** · 主要使用方：mm-modeling（选型）、mm-problem-analysis（判型）；对话模式用于快速回答"该用什么模型"。
> 本文件是人类可读的快速决策树；精确的模型参数与适用规模见 `model-selection-library.md` 与模型字典（脚本查询）。

## 第一步：输出是什么形态？

```
输出是一个数/一个方案（怎么分配、怎么安排）   → 优化类
输出是未来的数值序列（明天/明年是多少）       → 预测类
输出是一个排名/评分（哪个方案好）             → 评价类
输出是类别标签或分群                         → 分类/聚类类
输出是系统随时间的演化规律                    → 机理/动力学类
```

混合题型按主问题定主模型，子问题按需叠加方法。

## 第二步：按类走决策树

### 预测类

```
数据量 < 15 个点              → GM(1,1) 灰色预测（只适合近似指数增长）
纯时序、无外部变量            → ARIMA / 指数平滑 / Prophet
季节性明显                    → SARIMA（周期需预先指定）
多个影响因素、线性            → 多元回归 / 岭回归
多因素、非线性、数据 100+     → 随机森林 / XGBoost
长序列、强非线性、数据 1000+  → LSTM / GRU
需要不确定性区间              → Bootstrap / MCMC
```

### 评价类

```
要体现专家经验、有层次结构    → AHP（主观赋权）
纯数据驱动、要客观权重        → 熵权法
方案间算距离排序              → TOPSIS（配 AHP/熵权做权重）
指标是模糊语言（好/中/差）    → 模糊综合评价
评的是投入产出效率            → DEA
数据少、信息不全              → 灰色关联分析
指标多且高度相关              → PCA 降维 + TOPSIS
主客观权重都要               → AHP + 熵权组合
```

### 优化类

```
目标与约束全线性              → 线性规划 LP
含整数 / 0-1 变量             → 整数规划 MIP（milp/pulp）
非线性目标或约束              → 非线性规划 / 遗传算法 / 模拟退火
多目标相互冲突                → NSGA-II / 加权和法 / ε-约束法
序贯决策（阶段之间递进）      → 动态规划
路径/调度/分配的特例          → 先查图论与组合优化速查表
```

### 分类 / 聚类

```
有标签（监督）                → 随机森林 / SVM / Logistic 回归 / XGBoost
无标签（分群）                → K-means（要定 k）/ 层次聚类 / DBSCAN（密度、抗噪）
文本/情感                     → TF-IDF + LDA / 预训练词向量
类别极不平衡                  → 过采样/欠采样 + macro-F1 评估
```

### 机理 / 动力学

```
连续时间演化（SIR、种群）     → 常微分方程 ODE
空间扩散 / 连续场             → PDE / 有限差分
离散代际演化                  → 差分方程 / 马尔可夫链
不确定性大、解析解不可得      → 蒙特卡洛模拟
空间离散、规则网格演化        → 元胞自动机
```

### 图论 / 网络

```
最短路（无负权）              → Dijkstra；有负权 → Bellman-Ford
最大流 / 最小费用流           → 网络流模型（流量守恒必须验证）
二分匹配 / 任务指派           → 匈牙利算法 / 最大权匹配
覆盖 / 选址                   → 整数规划（集合覆盖）
TSP / VRP                     → 小规模精确解，大规模启发式 + 子回路消除
```

## 第三步：无论选什么，先过防错清单

1. 预测类：数据是否按时间切分？标准化是否只在训练集 fit？
2. 评价类：指标方向统一了吗？权重来源说明了吗？做了敏感性检验吗？
3. 优化类：非负/整数/容量约束齐了吗？取整后重新验证可行性了吗？
4. 机理类：单位、初始条件、求解器与步长收敛性写了吗？
5. 启发式：多起点稳定性验证了吗？敢不敢不写"全局最优"？

各条的展开见 `api-pitfalls.md`（API 级）与各模型详细指南（model-selection-library.md）。
