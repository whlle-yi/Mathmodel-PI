## scipy.optimize

- `minimize` 只做最小化。最大化利润/覆盖率/得分必须对目标函数取负，并在结果中还原真实目标值——论文里出现"最大收益 = -382"是典型的忘还原。
- 不等式约束约定是 `fun(x) >= 0`。容量约束（消耗 ≤ 上限）要写成 `上限 - 消耗 >= 0`，写反方向不报错、只是结果错。
- `constraints` 里 `type: "ineq"` 与 `"eq"` 别混；等式约束在 SLSQP 下对初值敏感，给可行初值。
- 不要轻信 `res.success`。必须把最优解**重新代入全部约束**，输出每条的值、松弛量和是否活跃；边界解常见于约束刚好压线。
- 整数变量：`minimize` 本身不支持整数约束。取整后必须重新验证可行性；不可行时用修复启发式，禁止直接四舍五入了事。真要整数规划用 `scipy.optimize.milp` 或 `pulp`。
- 多起点：非凸问题跑 10~30 个随机初值取最优，并报告稳定性；单次求解结果不写"全局最优"。
- `bounds` 里被夹在边界上的变量要在结果中讨论（是真实最优还是搜索失败）。

## scipy.integrate

- `solve_ivp` 默认 RK45 对刚性方程会极慢或发散；化学动力学、含大刚度比的问题用 `method="Radau"` 或 `"BDF"`。
- `t_eval` 不给的话只返回内部步长点，画图会出现"伪震荡"。
- 检查守恒量：能量、质量、种群总数在无耗散模型里应守恒，漂移说明步长或求解器有问题。
- `odeint`（老接口）与 `solve_ivp` 参数顺序不同，别混用两套教程的写法。

## numpy

- 整数除法在 Python 原生 `/` 是浮点，但 `np.int32` 数组间 `/` 也是浮点；`//` 才是整除。人数、车辆数出现 3.7 辆就是该取整没取整。
- `np.random.seed` 只管 `np.random.*` 旧接口；用 `default_rng(seed)` 时同一 seed 要贯穿所有随机调用点。
- 大数组的原地操作 `arr *= 2` 与 `arr = arr * 2` 在视图（切片）上行为不同，切片修改会污染原数组。
- `np.corrcoef` 对常数列返回 nan（方差为 0），不是 bug；常数指标要剔除并说明。
- 浮点比较一律用 `np.isclose`，`==` 判断浮点相等是经典错误。

## pandas

- `read_csv` 先查 `df.dtypes`、`df.isna().sum()`、编码（中文 CSV 常见 GBK，`encoding="gbk"` 或 `"utf-8-sig"`）。列名乱码时继续建模等于全错。
- 时间列必须 `pd.to_datetime` 后才能做时序切分；字符串排序的"时间顺序"是字典序陷阱。
- `groupby` 后聚合列名与业务含义对不上，多半是聚合错了列或 `as_index` 理解反了。
- `merge` 检查结果行数：比输入多 = 键重复导致笛卡尔积，比输入少 = 键没对上。
- SettingWithCopyWarning 不是废话：在切片副本上赋值经常静默丢失。

## sklearn

- **一切标准化器（scaler/encoder）只在训练集上 fit**，再 `transform` 测试集。在全集上 fit 是数据泄露，时序问题按时间划分后同样适用。
- 时序数据**禁止** `train_test_split` 随机打乱；用前切分或 `TimeSeriesSplit`。
- 分类报告别只看 accuracy：类别不平衡时准确率会骗人，看 macro-F1 / 混淆矩阵。
- 调参只能在验证集/交叉验证内做；测试集参与调参 = 测试集作废。
- `fit` 输入必须是二维特征矩阵，单特征要 `reshape(-1, 1)`——新手最常撞的报错。
- 交叉验证里做特征选择必须放进 Pipeline，在 CV 外先做特征选择同样是泄露。

## statsmodels

- OLS 汇总里看系数先看 `P>|t|` 再谈大小；不显著的系数解释机制是编故事。
- `sm.OLS(y, X)` 不自动加常数项，要 `sm.add_constant(X)`；漏加常数截距会进斜率，R² 虚高。
- ADF 检验 p 值 < 0.05 拒绝单位根 = 序列平稳；差分次数 d 由它确定，不是拍脑袋。
- ARIMA 的 (p, q) 用 ACF/PACF 截尾或 AIC/BIC 网格搜索确定，并在论文里给出定阶依据。

## matplotlib

- 中文字体：`plt.rcParams["font.sans-serif"] = ["Noto Sans SC", "SimSun"]` 并 `axes.unicode_minus=False`，否则中文变方框、负号消失。
- 论文图用 `dpi=300` 导出 PDF/PNG；导出后**必须打开看一眼**（图例遮挡、标签截断只有打开才发现）。
- 同类图颜色/线型统一；灰度打印仍可区分（用线型 + marker 区分系列，不只靠颜色）。
- 图内不写长标题，标题进论文 caption；坐标轴必须有物理量与单位。
- 保存图表对应的数据来源（CSV 或 JSON），论文引用的每个数值要能追溯。

## 通用数值纪律

- 随机算法固定种子并多次运行报均值±标准差；"跑一次挺好的"不是结果。
- 数值先看量纲：成本、时间、风险不同量纲直接相加是建模错误，先归一化或无量纲化。
- 结果文件（JSON/CSV）记录：关键参数、每条约束检查值、随机种子、运行方式——论文里每个数值都能追溯到这里。
- 报告里写"求解器返回最优"不如写"回代验证全部约束满足，松弛量 ≤ 1e-6"。
